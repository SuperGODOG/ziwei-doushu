## 疾厄宮三方四正分析

疾厄宮的健康判斷不能只看本宮，需結合三方四正共同判定。

### 三方四正組成

| 關係 | 宮位 | 對健康的影響 |
|------|------|--------------|
| **對宮** | 父母宮 | 遺傳體質、家族病史、幼年撫育對體格的影響 |
| **三合** | 兄弟宮 | 手足是否有相同體質傾向、能否得到照顧支援 |
| **三合** | 交友宮 | 生活圈習慣（飲食、作息、應酬）對健康的影響 |

### 分析原則

1. **父母宮主星廟旺 + 無煞** → 遺傳體質佳，先天基礎好
2. **父母宮化忌沖疾厄宮** → 遺傳疾病傾向明顯，需及早篩查
3. **兄弟宮煞多** → 手足間可能有相同體質弱點
4. **交友宮貪狼化祿或廉貞化祿** → 應酬過度、生活習慣影響健康

### 空宮處理

疾厄宮空宮借對宮父母宮主星分析。若父母宮亦有問題（陷落、化忌、煞多），則體質判定更需謹慎，宜多做預防檢查。

## 四化入疾厄宮

四化落入疾厄宮，代表不同性質的健康事件。

| 四化 | 健康含義 | 具體表現 |
|------|----------|----------|
| **化祿** | 體質不錯，但需防「福過招災」 | 易因享受過度（暴飲暴食、應酬）致病；富貴病；肥胖傾向 |
| **化權** | 體力好，恢復力強 | 但爭強好勝易受傷；工作壓力大導致慢性病 |
| **化科** | 疾病可控，多為輕症 | 醫療資源好，能及早發現；健康意識強 |
| **化忌** | 主要健康隱患點 | 慢性病、遺傳病、需長期關注；容易忽視發現晚 |

### 化忌入疾厄宮的深度判讀

化忌所在的星曜五行對應具體病灶：

- **太陽化忌入疾厄** → 心血管、眼部、頭部（陽火主上焦）
- **太陰化忌入疾厄** → 腎臟、婦科、內分泌、情緒相關疾病（陰水主下焦）
- **武曲化忌入疾厄** → 肺部、骨骼、金屬性外傷（金主肺、骨）
- **貪狼化忌入疾厄** → 生殖泌尿、肝膽（甲木壬水雙屬性）
- **廉貞化忌入疾厄** → 血液、神經、生殖（陰火主血）
- **天機化忌入疾厄** → 神經系統、肝膽、失眠焦慮
- **巨門化忌入疾厄** → 口腔、消化道、皮膚（暗星主陰疾）
- **天同化忌入疾厄** → 泌尿、內分泌、慢性虛損
- **文昌化忌入疾厄** → 神經性、與文書壓力相關（如頭痛、視力）
- **文曲化忌入疾厄** → 咽喉、口舌、情緒性疾病

## 大限流年疾厄宮觸發規則

疾病爆發的時機需綜合大限與流年判斷。

### 大限疾厄宮

**大限走到疾厄宮的十年** — 此十年須特別關注健康：

1. 大限疾厄宮**主星陷落 + 煞星** → 此十年體質下滑
2. 大限四化中的**化忌落入本命疾厄宮** → 此十年爆發本命帶的隱患
3. 大限四化中的**化忌沖大限疾厄宮**（即化忌入父母宮） → 遺傳性/慢性病顯現

### 流年疾厄宮觸發

流年天干四化與本命/大限疾厄宮的互動決定當年是否發病：

| 觸發模式 | 意義 |
|----------|------|
| 流年化忌入本命疾厄宮 | 當年健康事件爆發 |
| 流年化忌沖本命疾厄宮 | 當年體檢或就醫 |
| 流年疾厄宮遇擎羊 + 化忌 | 開刀、外傷、急症 |
| 流年疾厄宮遇陀羅 + 化忌 | 慢性病久治不癒 |
| 流年疾厄宮遇火星 + 化忌 | 急性炎症、發燒 |
| 三重疊忌（本命 + 大限 + 流年皆化忌在疾厄） | 重大疾病，需最高警惕 |

### 危險組合（Red Flag）

以下組合出現時，應強烈建議命主提前檢查、注意保養：

- 疾厄宮 + 對宮父母宮 皆化忌
- 疾厄宮 + 大限疾厄宮 + 流年疾厄宮 三宮位有 2 個以上化忌
- 疾厄宮見「羊陀夾忌」或「火鈴夾忌」
- 疾厄宮遇天刑 + 化忌 → 開刀機會

## 命身宮/福德宮/田宅宮的健康聯動

健康不只看疾厄宮，其他宮位的星曜配置對健康有間接但重要的影響。

### 命宮

- 命宮主星廟旺 → 整體氣血強，抗病能力佳
- 命宮遇多煞 → 體質先天偏弱
- 命身同宮 → 健康與命運強綁定，一榮俱榮一損俱損

### 身宮

身宮所在宮位影響後天健康傾向：
- **身宮在福德** → 精神壓力對健康影響最大
- **身宮在財帛** → 為財勞碌傷身
- **身宮在事業** → 過勞、職業病

### 福德宮

福德宮為疾厄宮的**氣數位**，直接影響精神健康與長壽：
- 福德宮化忌 → 焦慮、抑鬱、精神性疾病
- 福德宮遇地空地劫 → 精神空虛、易有輕生念頭
- 福德宮貪狼化忌 → 沉溺（酒、色、賭）傷身

### 田宅宮

田宅宮代表居住環境，間接影響健康：
- 田宅宮遇煞多 → 居家風水、水電問題影響健康
- 田宅宮化忌 → 房屋潮濕、通風差引發呼吸道/關節問題

## 健康注意

### 先天體質

根據疾厄宮主星判斷先天體質弱點。

### 後天調養

1. 飲食調理
2. 運動保健
3. 定期檢查
4. 情緒管理

### 流年健康

當疾厄宮逢煞星或化忌時，需特別注意健康。
