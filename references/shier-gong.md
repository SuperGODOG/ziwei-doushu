# 十二宮位詳解

## 宮位概述

紫微斗數以十二宮位為基本框架，每個宮位代表人生的不同面向。十二宮位以命宮為起點，逆時針排列。

---

## 命宮

### 基本含義

命宮是整個命盤的核心，代表命主本人的一切：

- **個性特質**：天生的性格傾向
- **人生格局**：一生的基本格局高低
- **行為模式**：處事風格與習慣
- **外貌氣質**：外在形象與氣場

### 分析重點

1. 命宮主星決定基本性格
2. 命宮輔煞星影響格局高低
3. 命宮四化決定人生起伏
4. 三方四正星曜影響整體運勢

### 各主星在命宮

| 主星 | 性格特點 |
|------|----------|
| 紫微 | 領導氣質、高傲、有主見 |
| 天機 | 聰明機變、善謀略、好動 |
| 太陽 | 光明磊落、熱心、愛面子 |
| 武曲 | 剛毅果決、重財、較孤僻 |
| 天同 | 溫和隨和、享樂、較懶散 |
| 廉貞 | 精明複雜、愛恨分明 |
| 天府 | 穩重保守、重名譽 |
| 太陰 | 情緒敏感、內斂、愛美 |
| 貪狼 | 多才多藝、慾望強 |

| 天相 | 隨和輔佐、守規矩 |

| 七殺 | 剛強衝勁、獨立 |
| 破軍 | 開創變動、不安定 |

## 空宮借對規則

空宮指該宮沒有十四主星坐守（輔星、煞星存在時仍算空宮）。紫微斗數中空宮極為常見，本身不代表吉凶。

### 空宮分析四步法

**第一步：先看空宮內部** — 空宮內的輔星、煞星、雜曜仍然重要，不可忽略。
**第二步：借對宮主星** — 將對宮主星借入分析。太陽、太陰等「亮星」借入約有八九成力量，其他星曜約六七成。
**第三步：三方四正** — 空宮本無吉凶，完全取決於三方四正的組合。組合好則大吉，組合差則大凶。
**第四步：兩夾影響** — 空宮被煞星（地空、地劫等）所夾時，影響加劇。

### 各宮對宮對照表

| 本宮 | 借星來源（對宮） |
|------|------------------|
| 命宮 | 遷移宮 |
| 兄弟宮 | 交友宮 |
| 夫妻宮 | 事業宮 |
| 子女宮 | 田宅宮 |
| 財帛宮 | 福德宮 |
| 疾厄宮 | 父母宮 |

| 田宅宮 | 子女宮 |

| 父母宮 | 疾厄宮 |

### 各宮空宮含義

- **命宮空宮**：性格較無固定模式，易受外界影響。借遷移宮主星分析，三方四正好仍為吉格。
- **夫妻宮空宮**：對感情隨緣，多參考事業宮主星。
- **財帛宮空宮**：借福德宮主星分析，忌化忌衝破。
- **疾厄宮空宮**：若三方四正好，反而身體健康（無特定偏差）。
- **田宅宮空宮**：借子女宮主星分析，有化祿、祿存仍主吉。

## 夾宮分析

夾宮指左右兩鄰宮的星曜對中間宮位施加無形影響。夾宮作用不如三方四正強烈，但無形中深刻影響命主境遇。

### 吉星夾

**魁鉞夾**：天魁、天鉞分居左右鄰宮。僅發生於**丙丁年生人（魁在亥、鉞在酉，夾戌宮）**與**壬癸年生人（魁在卯、鉞在巳，夾辰宮）**。主得長輩貴人暗中提攜，逢凶化吉，一生少走彎路。魁鉞在命盤中永不同宮。

**昌曲夾**：文昌、文曲分居左右鄰宮（丑、未時生人分夾丑、未）。主文采風華、思維敏捷、考運與名望順遂。

**輔弼夾**：左輔、右弼分居左右鄰宮（農曆四月、十月生人分夾丑、未）。主助力強大、貴人極多、團隊得力。

**祿權科夾**：化祿、化權、化科在左右鄰宮相夾。主福報加成、名利地位兼收。

### 凶星夾

**羊陀夾**：擎羊、陀羅分居左右。祿存坐守之宮必形成羊陀相夾（擎羊在前一宮，陀羅在後一宮）。主行事保守謹慎。若中間宮位再逢化忌，則構成凶險的「羊陀夾忌格」，主進退兩難、四面受敵。

**火鈴夾**：火星、鈴星分居左右鄰宮。主突發災禍、內心焦慮急躁、暗中損傷。最忌夾太陰或天相。

**空劫夾**：地空、地劫分居左右鄰宮。主虛耗損失、財來財去、行事易半途而廢。宜從事哲學、藝術或精神領域以化解。

### 夾宮通用原則

1. **吉星夾**：鄰宮吉星力量匯聚於中間宮位；但若中間宮位有化忌或惡煞，則吉力大打折扣。
2. **凶星夾**：中間宮位無論有無吉星，均受左右凶煞夾制與壓力；若中間宮位本身有化忌，則凶性全面引爆。
3. **天相最重夾宮**：天相受左右鄰宮影響極大：
   - 逢天梁（蔭星）與化祿/祿存（財星）相夾 → 構成**財蔭夾印格**（大吉，得富貴長輩之蔭庇）
   - 逢化忌（巨門化忌等）與擎羊/天刑相夾 → 構成**刑忌夾印格**（大凶，主官非是非、刑傷災厄）
4. 所有吉格遇惡煞（羊陀、火鈴、空劫）緊夾均為破格，秀而不實，福澤受損。
