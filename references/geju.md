# 格局分析

## 格局概述

格局是紫微斗數中對命盤整體結構的評估，反映命主的人生格局高低和發展潛力。

每個格局按三層條件判定：

| 層級 | 含義 | 判斷方式 |
|------|------|----------|
| **required** | 必須滿足，缺一不可 | 逐條對照命盤，全部通過格局才成立 |
| **bonus** | 加分項，非必須 | 滿足時格局層次提升，不滿足不影響格局成立 |
| **breaking** | 破格條件，一旦觸發格局不成立或大打折扣 | 優先檢查，在 required 之前先看是否有破格 |

> 分析步驟：先看 breaking → 再看 required → 最後看 bonus。

## 吉格

### 紫府同宮格

**出處**：《紫微斗數全書》

**required**：
- 紫微、天府同宮

**bonus**：
- 同宮無煞星 → 大富大貴
- 左輔右弼在三方 → 貴人扶持，格局更穩

**breaking**：
- 地空或地劫同宮 → 有名無實，虛有其表
- 擎羊同宮 → 權力中帶刑傷

**意義**：
- 帝星財庫同宮，大富大貴之格
- 穩重有權有財，一生順遂

---

### 日月同輝格（日月並明格）

**出處**：《骨髓賦》

**required**：
- 太陽在巳宮（或卯宮）入廟，太陰在酉宮（或亥宮）入廟，三方四正並明會照（日巳月酉或日卯月亥）
- （注：太陽太陰在丑未同宮守命者為「日月同宮格」）

**bonus**：
- 日月皆廟旺無破 → 名利雙收，貴不可言
- 無煞星在三方 → 陰陽調和，大富大貴

**breaking**：
- 太陽落陷失輝 → 貴氣大減
- 太陰落陷失明 → 財庫受損，女命尤忌
- 逢化忌或陀羅衝破 → 陰陽失調，反多波折

**意義**：
- 陰陽調和，文武雙全
- 名利雙收，極品貴格

### 武貪格

**出處**：《紫微斗數全集》

**required**：
- 武曲、貪狼同宮

**bonus**：
- 貪狼廟旺（辰戌丑未）→ 偏財運強，創業有成
- 祿存或化祿在三方 → 財源廣進

**breaking**：
- 貪狼落陷化忌 → 欲望失控，反因財招禍
- 地空地劫同宮 → 財來財去，難守成

**意義**：
- 財星桃花星結合，白手起家
- 適合經商，有偏財運，社交能力強

### 機月同梁格

**出處**：《紫微斗數全書》

**required**：
- 天機、太陰、天同、天梁四星會聚三方四正（無需全部同宮，在三方會照即可）

**bonus**：
- 四星皆廟旺 → 公職穩步高升
- 無煞星在三方 → 體制內順遂

**breaking**：
- 貪狼或七殺在三方 → 不安於體制，難守成
- 化忌在三方四正 → 文書錯誤、職場是非

**意義**：
- 適合公職、體制內，穩定發展
- 文職有成，不適合創業

### 府相朝垣格

**出處**：《紫微斗數全集》

**required**：
- 天府、天相在三方四正會照

**bonus**：
- 天相廟旺 → 輔佐得位
- 化祿在財帛宮 → 財權並重

**breaking**：
- 羊陀夾天相 → 輔佐失位，有職無權
- 天府遇空劫 → 財庫空虛

**意義**：
- 權貴穩固，有權有財，穩重發展
- 格局穩健，事業順遂，財務穩定

**breaking**：
- 三奇中任一化忌入三方 → 不成立（嘉會忌破）

**意義**：

### 明珠出海格

**出處**：《骨髓賦》

**required**：
- 命宮立於未宮且無正曜（空宮），卯宮太陽入廟、亥宮太陰入廟，從卯亥兩宮並明會照未宮命宮
- （注：若太陽在卯宮立命，則為「日出扶桑格 / 日照雷門格」）

**bonus**：
- 命宮有左輔、右弼、文昌、文曲等吉星加會 → 財官雙美，少年得志
- 祿存、化祿在三方拱照 → 貴顯名揚

**breaking**：
- 卯宮太陽或亥宮太陰逢化忌、擎羊、陀羅衝破 → 珠玉蒙塵
- 地空、地劫同宮或衝照 → 虛名虛利

**意義**：
- 日月並明照命，主心地光明、才華橫溢、早年得志
- 適合文教、傳播、公職、大企業發展

### 火貪格 / 鈴貪格

**出處**：《紫微斗數全集》

**bonus**：
- 貪狼廟旺（辰戌丑未）→ 橫發力度極強
- 祿存或化祿在三方 → 暴富後能守住

**breaking**：
- 貪狼落陷化忌 → 橫發不成反橫破
- 地空地劫同宮 → 發後即散，曇花一現

**意義**：
- 意外發達，大起大落，橫發之格
- 可能暴富，也可能暴跌，不穩定但有爆發力

## 凶格

### 命無正曜格

**出處**：《紫微斗數全集》

**required**：
- 命宮無十四主星

**bonus**：
- 對宮遷移宮主星廟旺 → 借星後格局不差
- 命宮輔星吉多 → 可補無正曜之缺

**breaking**：
- 對宮亦空宮 → 雙空無借，格局極弱
- 命宮煞星多 → 無主星制煞，煞氣無制

**意義**：
- 格局較低，需靠對宮星
- 看三方四正和夾宮，輔星可提升

---

### 殺破狼格

**出處**：《紫微斗數全集》

**required**：
- 七殺、破軍、貪狼三顆星在三方四正會聚（亥卯未或巳酉丑三合）

**bonus**：
- 命宮主星廟旺 + 無煞星衝照 → 變動力轉化為開創力
- 化權在三方 → 變動中有主導權

**breaking**：
- 貪狼落陷化忌 → 變動力有餘但收穫打折
- 七殺遇空劫 → 衝動而缺乏持續力
- 破軍遇化忌 → 變動帶來破壞而非建設

**意義**：
- 變動極大，開創破壞，大起大落
- 一生波折但有開創力，不安於現狀

---

### 鈴昌陀武格

**出處**：《骨髓賦》（「鈴昌陀武，限至投河」）

**required**：
- 鈴星、文昌、陀羅、武曲四星在辰、戌、丑、未四墓宮交會或同度（尤忌在辰戌宮）

**bonus**：
- 無（此格為著名凶敗格局，無加分項）

**breaking**：
- 缺陀羅或鈴星且三方無化忌引動 → 格局不成立（僅為普通星曜組合）
- 逢化科、天梁、祿存同宮吉化 → 凶險程度大為減輕，有化解之機

**意義**：
- 大凶之格，主重大挫敗、水厄、官非牢獄、意外之災或心態陷入絕境
- 行運、流年逢此格局或煞忌引動時需高度防範，宜行事低調、避免高風險投機或涉險

### 天刑地劫格

**bonus**：

## 格局高低判斷

### 高格局條件

1. **主星廟旺**：命宮主星在廟旺位置
2. **輔星入命**：左輔右弼、魁鉞等輔星
3. **四化吉利**：化祿、化權、化科入命
4. **無煞星破**：沒有煞星破壞格局
5. **三方四正吉**：三方四正星曜配置佳

### 低格局條件

1. **主星陷落**：命宮主星在陷落位置
2. **煞星入命**：多顆煞星入命
3. **化忌入命**：化忌星入命
4. **格局被破**：吉格被煞星破壞
5. **空宮無星**：命宮空宮且對宮也弱

---

## 格局化解

### 化解方法

1. **行運提升**：等待好運到來
2. **職業選擇**：選擇適合的行業
3. **修身養性**：提升個人修養
4. **外應輔助**：風水、佈局等

### 注意事項

- 格局高不代表一帆風順
- 格局低不代表沒有機會
- 需結合大運流年分析
- 個人努力很重要

## 格局等級判定標準（星格 + 數格體系）

紫微斗數判斷命局等級，通過**星格**（主貴氣、社會能力）與**數格**（主富氣、財富層次）兩個維度綜合評定，配合形成九種品位。

### 一、星格等級判定（主貴氣）

| 等級 | 判定標準 |
|------|----------|
| **上格** | 命入富貴格局且無破；或命宮正星廟旺，聚吉，有科權祿守照，三方四正皆為吉星 |
| **中格** | ①命宮正星不入廟但得地平性，聚吉有科權祿守照；②命宮正星入廟但吉凶相半混雜；③命宮無正星但三方吉多無煞忌 |
| **下格** | 正星失陷或落閒宮，本宮及三方四正皆有惡煞 |

### 二、數格等級判定（主富氣）

| 等級 | 判定標準 |
|------|----------|
| **上格** | 星得落宮陰陽五行相生，且落宮為長生、冠帶、臨官、帝旺之宮 |
| **中格** | ①星與落宮陰陽五行相同且落宮為胎、養之宮；②落宮旺相但陰陽相剋；③陰陽相生但逢沐浴衰絕 |
| **下格** | 星受落宮陰陽五行相剋，且落宮處衰、絕、死之位 |

### 三、星格與數格九品組合

| 品位 | 星格 | 數格 | 古代對應 | 歸類 |
|------|------|------|----------|------|
| 第一 | 上格 | 上格 | 君王、首相、元首級 | 上等享福 |
| 第二 | 上格 | 中格 | 三公、總理級以上 | 上等享福 |
| 第三 | 上格 | 下格 | 六卿、部長級以上 | 上等享福 |
| 第四 | 中格 | 上格 | 省級以上官員 | 中等享福 |
| 第五 | 中格 | 中格 | 地、縣級以上官員 | 中等享福 |
| 第六 | 中格 | 下格 | 科級以上或老闆 | 中等享福 |
| 第七 | 下格 | 上格 | 衣祿豐足、富裕之人 | 下等 |
| 第八 | 下格 | 中格 | 衣食不缺、小康之家 | 下等 |
| 第九 | 下格 | 下格 | 辛苦勞碌、貧窮夭折 | 下等 |

> 星格權重略重於數格。星格上格配數格下格仍可達高位，星格下格配數格上格僅能富裕而難顯貴。

### 四、格局純度判定指南

當 reference 未標註格局等級時，基於以下原則推斷：

**格局等級推斷**：
- 主星廟旺 + 吉星輔助 + 無煞星衝破 → 上格
- 主星平或得地 + 部分吉星 + 少量煞星（1-2 顆）→ 中格
- 主星陷落 + 煞星多（3 顆以上）+ 格局條件不完整 → 下格

**格局純度**：

| 純度 | 標準 |
|------|------|
| **完整形成** | 格局條件全部滿足，無煞星在關鍵位置，有吉星加護 |
| **部分形成** | 格局條件基本滿足，有 1-2 煞星但不破壞格局主體 |
| **破格** | 煞星直接衝破格局核心條件，或關鍵條件不滿足 |

**破格影響程度**：
- **輕微**：1 煞星在同宮或三方，不影響格局主體 → 格局成立，層次略降
- **中等**：2 煞星在關鍵位置 → 格局成立但福澤減半
- **嚴重**：煞星直接衝破核心條件（如紫府同宮遇地空地劫同宮）→ 格局不成立或有名無實
