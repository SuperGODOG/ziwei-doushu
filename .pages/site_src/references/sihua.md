# 四化飛星詳解

## 四化概述

四化是紫微斗數中最重要的動態元素，由年干決定，代表星曜的能量轉化。

| 四化 | 性質 | 能量 | 作用 |
|------|------|------|------|
| **化祿** | 吉 | 增益 | 財富、順利、人緣 |
| **化權** | 吉 | 掌控 | 權力、主導、競爭 |
| **化科** | 吉 | 名聲 | 貴人、考試、名望 |
| **化忌** | 凶 | 阻礙 | 執著、是非、困難 |

## 四化組合

當化祿、化權、化科同時出現在三方四正：

- **三奇嘉會**：名利雙收、大吉
- **雙祿交流**：祿存與化祿同宮，財運極佳

## 飛星四化

### 本命四化

由出生年干決定，影響一生。

### 大限四化

由大限天干決定，影響該十年。

### 流年四化

由流年天干決定，影響該年。

### 四化重疊

- **疊祿**：雙重好運
- **疊權**：權力極大
- **疊科**：名聲極佳
- **疊忌**：問題嚴重

---

## 化忌解法

### 化解方式

1. **化科解忌**：科星可緩解忌星
2. **祿存解忌**：祿存可減輕化忌
3. **行運轉化**：等待好運到來
4. **外應輔助**：佩戴、布局等

### 注意事項

- 化忌不一定全凶，有時代表執著、專注
- 要看化忌所在宮位和星曜
- 結合整體命盤分析

## 來因宮

來因宮又稱「化氣宮」，是紫微斗數命盤上**宮位天干與出生年天干相同**的那個宮位，為生年四化的起源點。

### 來因宮定位

| 出生年天干 | 來因宮位置 |
|-----------|-----------|
| 甲 | 戌宮 |
| 乙 | 酉宮 |
| 丙 | 申宮 |
| 丁 | 未宮 |
| 戊 | 午宮 |
| 己 | 巳宮 |
| 庚 | 辰宮 |
| 辛 | 卯宮 |
| 壬 | 寅宮 |
| 癸 | 亥宮 |

> 子、丑二宮不取來因宮（天開於子，地闢於丑，人生於寅）。

### 來因宮核心含義

- 來因宮是**生年四化的源頭**，賦予四化方向性
- 代表此生**核心課題**與人生重心
- 同一生年四化，來因宮不同，意義完全不同
- 大限、流年走到來因宮時，常是人生轉折點

### 來因宮落十二宮分類

**自立格**（需靠自己）：
- 命宮：自我性格修養
- 財帛宮：對錢財在意，有賺錢動力
- 官祿宮：事業心強，為工作而來
- 遷移宮：需外出歷練
- 福德宮：精神層面修行
- 疾厄宮：關注健康，喜自由業

**它立格**（需借助外力）：
- 父母宮：原生家庭影響一生
- 兄弟宮：需處理合夥人/同事關係
- 夫妻宮：需處理婚姻/異性關係
- 子女宮：與合作、桃花有關
- 交友宮：離不開朋友和社會關係
- 田宅宮：注重家庭、祖產

## 宮位飛化分析方法

飛星四化的核心公式：**A 宮（發射宮）→ 四化入 B 宮（接收宮）→ 沖/照 C 宮（B 的對宮）**

### 一、基本概念

**我宮（六內宮）**：命宮、財帛宮、疾厄宮、官祿宮、田宅宮、福德宮
**他宮（六外宮）**：兄弟宮、夫妻宮、子女宮、遷移宮、交友宮、父母宮

**原則**：
- 四化入我宮主吉（得到），入他宮主凶（付出/損失）
- 忌沖我宮主凶，忌沖他宮相對較輕

### 二、發射宮 → 接收宮 → 沖照宮

**沖與照**：
- 化忌入某宮 → 該宮對宮為「被沖」（多主凶）
- 化祿/權/科入某宮 → 該宮對宮為「被照」（多主吉）

**宮位分類判斷**：
- 六親宮（兄、夫、子、僕、父）化忌沖命宮 → 該六親緣薄
- 六事宮（財、疾、遷、官、田、福）化忌沖命宮 → 該事項有破
- 任何宮位忌沖本命命宮 → 必有凶象

### 三、祿忌因果關係

- **祿隨忌走**：化祿走向化忌方向，象徵事情結束（如出國後很少回來）
- **忌隨祿走**：化忌走向化祿方向，象徵事情反覆（如出國後經常回來）
- 化祿為「因」，化忌為「果」，構成一生一滅的因緣整體

### 四、體用對待法

- **本命盤**：命宮為體，其餘十一宮為用 → 用沖體主凶
- **大運與流年**：本命宮位為體，大運流年同類宮位為用 → 用沖體主凶

**同類宮職忌沖**：
- 大運夫妻宮忌沖本命夫妻宮 → 此大運婚姻亮紅燈
- 大運疾厄宮忌沖本命疾厄宮 → 健康亮紅燈

### 五、飛化分析要訣

1. 先看生年四化（本命基調），再看宮干飛化（動態事件）
2. 發射宮若有生年四化坐守，飛化力量更強；若有自化，能量洩漏
3. 接收宮若有生年四化，則強勢接收飛化能量
4. 命宮化忌沖對宮 → 該事項不利（如沖夫妻宮主婚姻不順）
5. 自化忌 → 該宮不美，有收藏、保守之意（疾厄宮例外，主不易得病）
