    格局分析

    格局概述

    格局是紫微斗數中對命盤整體結構的評估，反映命主的人生格局高低和發展潛力。

    每個格局按三層條件判定：

    層級 含義 判斷方式
    required 必須滿足，缺一不可 逐條對照命盤，全部通過格局才成立
    bonus 加分項，非必須 滿足時格局層次提升，不滿足不影響格局成立
    breaking 破格條件，一旦觸發格局不成立或大打折扣 優先檢查，在 required 之前先看是否有破格

    分析步驟：先看 breaking → 再看 required → 最後看 bonus。

    吉格

    紫府同宮格

    出處：《紫微斗數全書》

    required： - 紫微、天府同宮

    bonus： - 同宮無煞星 → 大富大貴 - 左輔右弼在三方 → 貴人扶持，格局更穩

    breaking： - 地空或地劫同宮 → 有名無實，虛有其表 - 擎羊同宮 → 權力中帶刑傷

    意義： - 帝星財庫同宮，大富大貴之格 - 穩重有權有財，一生順遂

    日月同輝格

    出處：《骨髓賦》

    required： - 太陽、太陰同宮或對照（丑宮最佳：太陽漸旺，太陰尚明）

    bonus： - 日月皆廟旺 → 名利雙收 - 無煞星在三方 → 陰陽調和，不爭不亂

    breaking： - 太陽落陷（酉戌亥）→ 日失其光，格局大打折扣 - 太陰落陷（卯辰巳）→ 月失其明，女命尤忌

    意義： - 陰陽調和，文武雙全 - 名利雙收

    武貪格

    出處：《紫微斗數全集》

    required： - 武曲、貪狼同宮

    bonus： - 貪狼廟旺（辰戌丑未）→ 偏財運強，創業有成 - 祿存或化祿在三方 → 財源廣進

    breaking： - 貪狼落陷化忌 → 欲望失控，反因財招禍 - 地空地劫同宮 → 財來財去，難守成

    意義： - 財星桃花星結合，白手起家 - 適合經商，有偏財運，社交能力強

    機月同梁格

    出處：《紫微斗數全書》

    required： - 天機、太陰、天同、天梁四星會聚三方四正（無需全部同宮，在三方會照即可）

    bonus： - 四星皆廟旺 → 公職穩步高升 - 無煞星在三方 → 體制內順遂

    breaking： - 貪狼或七殺在三方 → 不安於體制，難守成 - 化忌在三方四正 → 文書錯誤、職場是非

    意義： - 適合公職、體制內，穩定發展 - 文職有成，不適合創業

    府相朝垣格

    出處：《紫微斗數全集》

    required： - 天府、天相在三方四正會照

    bonus： - 天相廟旺 → 輔佐得位 - 化祿在財帛宮 → 財權並重

    breaking： - 羊陀夾天相 → 輔佐失位，有職無權 - 天府遇空劫 → 財庫空虛

    意義： - 權貴穩固，有權有財，穩重發展 - 格局穩健，事業順遂，財務穩定

    三奇嘉會格

    出處：《紫微斗數全書》

    required： - 化祿、化權、化科同時出現在命宮三方四正

    bonus： - 三奇同宮 → 極品之貴 - 無煞星衝破 → 一生順遂

    breaking： - 三奇中任一化忌入三方 → 不成立（嘉會忌破） - 地空地劫在三方 → 有名無實

    意義： - 財權名兼備，大吉之格 - 極為難得，發展極佳

    雙祿交流格

    出處：《紫微斗數全集》

    required： - 祿存與化祿同宮或對照

    bonus： - 雙祿同在命宮或財帛宮 → 財運極旺 - 無煞星 → 守財有道

    breaking： - 地空地劫同宮 → 祿被空劫破，財聚財散 - 化忌對沖 → 雙祿被忌衝破

    意義： - 財運極佳，雙重財祿 - 財源廣進，一生富足

    祿馬交馳格

    出處：《紫微斗數全書》

    required： - 祿存與天馬同宮

    bonus： - 化祿亦同宮或對照 → 財從四方來 - 遷移宮廟旺 → 出外大利

    breaking： - 地空地劫同宮 → 奔波無獲 - 遷移宮化忌 → 出外受阻，祿馬難行

    意義： - 財從外來，發達之象 - 適合外出發展，動中生財

    明珠出海格

    出處：《骨髓賦》

    required： - 太陽在卯宮（日出扶桑之位）

    bonus： - 太陰在亥宮同時 → 日月並明，極品 - 無煞星 → 名聲遠播無阻

    breaking： - 太陽遇擎羊或地劫 → 光芒被掩 - 命宮無吉星輔助 → 空有虛名

    意義： - 光芒萬丈，名聲遠播 - 適合公開行業，有知名度，政治緣分

    月朗天門格

    出處：《骨髓賦》

    required： - 太陰在亥宮（月朗天門之位）

    bonus： - 祿存或化祿同宮 → 財運極旺 - 文昌文曲在三方 → 文采出眾

    breaking： - 太陰遇火星或鈴星 → 月被火侵，破財 - 地劫同宮 → 財來財去

    意義： - 財運極佳，女性貴人多，內斂有財 - 適合房地產，女性緣佳

    火貪格 / 鈴貪格

    出處：《紫微斗數全集》

    required： - 火星或鈴星與貪狼同宮

    bonus： - 貪狼廟旺（辰戌丑未）→ 橫發力度極強 - 祿存或化祿在三方 → 暴富後能守住

    breaking： - 貪狼落陷化忌 → 橫發不成反橫破 - 地空地劫同宮 → 發後即散，曇花一現

    意義： - 意外發達，大起大落，橫發之格 - 可能暴富，也可能暴跌，不穩定但有爆發力

    鈴昌陀武格（吉化）

    出處：《紫微斗數全書》

    required： - 鈴星、文昌、武曲會聚（無陀羅）

    bonus： - 武曲廟旺 → 專業權威 - 化科或化權同宮 → 技術成名

    breaking： - 陀羅同宮 → 此格局變為凶格（見凶格部分）

    意義： - 武職出頭，專業能力強，技術有成

    凶格

    命無正曜格

    出處：《紫微斗數全集》

    required： - 命宮無十四主星

    bonus： - 對宮遷移宮主星廟旺 → 借星後格局不差 - 命宮輔星吉多 → 可補無正曜之缺

    breaking： - 對宮亦空宮 → 雙空無借，格局極弱 - 命宮煞星多 → 無主星制煞，煞氣無制

    意義： - 格局較低，需靠對宮星 - 看三方四正和夾宮，輔星可提升

    殺破狼格

    出處：《紫微斗數全集》

    required： - 七殺、破軍、貪狼三顆星在三方四正會聚（亥卯未或巳酉丑三合）

    bonus： - 命宮主星廟旺 + 無煞星衝照 → 變動力轉化為開創力 - 化權在三方 → 變動中有主導權

    breaking： - 貪狼落陷化忌 → 變動力有餘但收穫打折 - 七殺遇空劫 → 衝動而缺乏持續力 - 破軍遇化忌 → 變動帶來破壞而非建設

    意義： - 變動極大，開創破壞，大起大落 - 一生波折但有開創力，不安於現狀

    鈴昌陀武格（凶化）

    出處：《紫微斗數全書》

    required： - 鈴星、文昌、陀羅、武曲同宮

    bonus： - 無（此格本身為凶，無加分項）

    breaking： - 無陀羅 → 此格不成立，變為吉格的「鈴昌武」格局

    意義： - 意外災禍，官非是非 - 需要化解，避免高危活動

    天刑地劫格

    出處：《紫微斗數全集》

    required： - 天刑、地劫同宮

    bonus： - 命宮主星廟旺 → 可部分化解 - 化科同宮 → 法律文書有貴人

    breaking： - 同宮再有化忌 → 刑訟必應 - 在命宮或遷移宮 → 影響最重

    意義： - 刑訟是非，法律糾紛，困難重重

    羊陀夾忌格

    出處：《紫微斗數全集》

    required： - 擎羊、陀羅分居左右兩鄰宮，中間夾化忌星

    bonus： - 化科在夾宮中間 → 貴人可解 - 祿存在夾宮 → 壓力中有收穫

    breaking： - 中間宮位主星陷落 → 雪上加霜 - 空劫在夾宮外圍 → 四面楚歌

    意義： - 極為不利，進退兩難，困難加倍 - 需吉星解救或行運轉化

    火鈴夾命格

    出處：《紫微斗數全集》

    required： - 火星、鈴星分別在命宮左右兩鄰宮

    bonus： - 命宮主星廟旺 → 可駕馭煞氣 - 祿存或化祿在命宮 → 急中求財

    breaking： - 命宮主星陷落 → 災禍頻繁 - 命宮再有空劫 → 火上澆油

    意義： - 災禍頻繁，意外較多，格局降低

    空劫入命格

    出處：《紫微斗數全集》

    required： - 地空、地劫同時在命宮

    bonus： - 從事藝術、宗教、哲學 → 可化空劫為創作力 - 命宮有文昌文曲 → 才華可部分化解

    breaking： - 命宮主星陷落 → 虛耗加倍 - 財帛宮再有煞星 → 財運極差

    意義： - 虛耗損失，財運不佳，格局降低 - 適合藝術宗教，精神層面發展

    巨門化忌格

    出處：《紫微斗數全書》

    required： - 巨門化忌，且在命宮、遷移宮或福德宮

    bonus： - 祿存或化祿同宮 → 口舌生財，爭議中獲利 - 文昌同宮 → 口才有節制

    breaking： - 擎羊同宮 → 口舌引發衝突 - 火星同宮 → 言辭傷人

    意義： - 口舌是非，爭吵衝突，人際不順

    廉貞化忌格

    出處：《紫微斗數全書》

    required： - 廉貞化忌

    bonus： - 天府同宮 → 可穩住廉貞的浮動 - 化科在三方 → 官司中遇貴人

    breaking： - 擎羊或陀羅同宮 → 官非必應 - 在命宮或官祿宮 → 影響最深

    意義： - 囚星化忌，官非、牢獄之災風險 - 感情是非

    格局高低判斷

    高格局條件

    1. 主星廟旺：命宮主星在廟旺位置
    2. 輔星入命：左輔右弼、魁鉞等輔星
    3. 四化吉利：化祿、化權、化科入命
    4. 無煞星破：沒有煞星破壞格局
    5. 三方四正吉：三方四正星曜配置佳

    低格局條件

    1. 主星陷落：命宮主星在陷落位置
    2. 煞星入命：多顆煞星入命
    3. 化忌入命：化忌星入命
    4. 格局被破：吉格被煞星破壞
    5. 空宮無星：命宮空宮且對宮也弱

    格局化解

    化解方法

    1. 行運提升：等待好運到來
    2. 職業選擇：選擇適合的行業
    3. 修身養性：提升個人修養
    4. 外應輔助：風水、佈局等

    注意事項

    • 格局高不代表一帆風順
    • 格局低不代表沒有機會
    • 需結合大運流年分析
    • 個人努力很重要

    格局等級判定標準（星格 + 數格體系）

    紫微斗數判斷命局等級，通過星格（主貴氣、社會能力）與數格（主富氣、財富層次）兩個維度綜合評定，配合形成九種品位。

    一、星格等級判定（主貴氣）

    等級 判定標準
    上格 命入富貴格局且無破；或命宮正星廟旺，聚吉，有科權祿守照，三方四正皆為吉星
    中格 ①命宮正星不入廟但得地平性，聚吉有科權祿守照；②命宮正星入廟但吉凶相半混雜；③命宮無正星但三方吉多無煞忌
    下格 正星失陷或落閒宮，本宮及三方四正皆有惡煞

    二、數格等級判定（主富氣）

    等級 判定標準
    上格 星得落宮陰陽五行相生，且落宮為長生、冠帶、臨官、帝旺之宮
    中格 ①星與落宮陰陽五行相同且落宮為胎、養之宮；②落宮旺相但陰陽相剋；③陰陽相生但逢沐浴衰絕
    下格 星受落宮陰陽五行相剋，且落宮處衰、絕、死之位

    三、星格與數格九品組合

    品位 星格 數格 古代對應 歸類
    第一 上格 上格 君王、首相、元首級 上等享福
    第二 上格 中格 三公、總理級以上 上等享福
    第三 上格 下格 六卿、部長級以上 上等享福
    第四 中格 上格 省級以上官員 中等享福
    第五 中格 中格 地、縣級以上官員 中等享福
    第六 中格 下格 科級以上或老闆 中等享福
    第七 下格 上格 衣祿豐足、富裕之人 下等
    第八 下格 中格 衣食不缺、小康之家 下等
    第九 下格 下格 辛苦勞碌、貧窮夭折 下等

    星格權重略重於數格。星格上格配數格下格仍可達高位，星格下格配數格上格僅能富裕而難顯貴。

    四、格局純度判定指南

    當 reference 未標註格局等級時，基於以下原則推斷：

    格局等級推斷： - 主星廟旺 + 吉星輔助 + 無煞星衝破 → 上格 - 主星平或得地 + 部分吉星 + 少量煞星（1-2 顆）→ 中格 - 主星陷落 + 煞星多（3 顆以上）+ 格局條件不完整 → 下格

    格局純度：

    純度 標準
    完整形成 格局條件全部滿足，無煞星在關鍵位置，有吉星加護
    部分形成 格局條件基本滿足，有 1-2 煞星但不破壞格局主體
    破格 煞星直接衝破格局核心條件，或關鍵條件不滿足

    破格影響程度： - 輕微：1 煞星在同宮或三方，不影響格局主體 → 格局成立，層次略降 - 中等：2 煞星在關鍵位置 → 格局成立但福澤減半 - 嚴重：煞星直接衝破核心條件（如紫府同宮遇地空地劫同宮）→ 格局不成立或有名無實
