    事業財富分析

    事業宮（官祿宮）

    事業宮代表工作、職業、事業發展和社會地位。

    事業宮主星分析

    紫微在事業宮

    事業特點： - 適合領導管理 - 有權威地位 - 大企業、政府

    適合行業： - 高層管理 - 政治 - 大型企業

    天機在事業宮

    事業特點： - 適合企劃謀略 - 變動性工作 - 需要動腦

    適合行業： - 企劃 - 顧問 - 科技

    太陽在事業宮

    事業特點： - 適合公開行業 - 有名聲 - 服務大眾

    適合行業： - 公職 - 教育 - 媒體

    武曲在事業宮

    事業特點： - 財星入事業 - 與金錢相關 - 執行力強

    適合行業： - 金融 - 銀行 - 軍警

    天同在事業宮

    事業特點： - 福利事業 - 服務業 - 輕鬆工作

    適合行業： - 社會福利 - 服務業 - 藝術

    廉貞在事業宮

    事業特點： - 公關交際 - 法律相關 - 競爭激烈

    適合行業： - 法律 - 公關 - 娛樂

    天府在事業宮

    事業特點： - 穩定發展 - 財務相關 - 管理職

    適合行業： - 金融 - 房地產 - 行政管理

    太陰在事業宮

    事業特點： - 適合房產 - 夜間工作 - 女性相關

    適合行業： - 房地產 - 夜場 - 美容

    貪狼在事業宮

    事業特點： - 娛樂行業 - 交際應酬 - 多元發展

    適合行業： - 娛樂 - 餐飲 - 藝術

    巨門在事業宮

    事業特點： - 靠口舌吃飯 - 專業服務 - 需要表達

    適合行業： - 法律 - 醫療 - 教育

    天相在事業宮

    事業特點： - 輔佐他人 - 幕僚職位 - 穩定發展

    適合行業： - 秘書 - 幕僚 - 行政

    天梁在事業宮

    事業特點： - 公益服務 - 教育醫療 - 幫助他人

    適合行業： - 教育 - 醫療 - 公益

    七殺在事業宮

    事業特點： - 開創型 - 軍警武職 - 獨立作業

    適合行業： - 軍警 - 創業 - 技術

    破軍在事業宮

    事業特點： - 變動大 - 改革創新 - 不安定

    適合行業： - 創新行業 - 外銷 - 運動

    財帛宮

    財帛宮代表財富收入、理財方式和財運狀況。

    財帛宮主星分析

    財星（武曲、太陰、天府）

    財運特點： - 正財運佳 - 理財能力強 - 財源穩定

    其他主星

    根據主星特性判斷財運方式和程度。

    財運吉凶

    財運佳條件

    1. 財帛宮主星廟旺
    2. 化祿入財帛宮
    3. 祿存入命或財帛
    4. 無煞星破壞
    5. 武曲、天府等財星旺

    財運差條件

    1. 財帛宮主星陷落
    2. 化忌入財帛宮
    3. 煞星入財帛宮
    4. 地空地劫入命
    5. 破軍、七殺帶煞

    創業與打工

    適合創業

    • 命宮主星強勢（紫微、七殺等）
    • 事業宮有開創星（破軍、七殺等）
    • 財帛宮財星旺
    • 有左輔右弼扶持

    適合打工

    • 命宮主星穩重（天府、天相等）
    • 事業宮有輔佐星
    • 適合體制內發展
    • 機月同梁格局

    事業宮三方四正分析

    事業宮不能孤立看，必須與三方四正共同判定。

    三方四正組成

    關係 宮位 分析重點
    對宮 夫妻宮 配偶對事業的助力/阻力、感情狀態是否影響事業投入度
    三合 命宮 個人特質與事業方向的匹配度
    三合 遷移宮 外出發展機會、貴人來源、業務往來

    分析原則

    1. 命宮主星廟旺 + 事業宮吉星 → 個人能力與事業機遇匹配，發展順遂
    2. 夫妻宮化祿 → 事業宮 → 配偶帶財或推動事業
    3. 夫妻宮化忌 → 事業宮 → 婚姻壓力拖累事業，或事業投入影響婚姻
    4. 遷移宮廟旺主星 + 化祿 → 適合外出發展、業務型工作
    5. 遷移宮多煞 → 出外不利，宜守本地

    空宮處理

    事業宮空宮借對宮夫妻宮主星分析： - 夫妻宮主星廟旺 → 事業借光配偶，可能夫妻共事或配偶帶動 - 夫妻宮陷落 → 事業方向不明，需依三合命宮/遷移宮定位

    財帛宮三方四正分析

    三方四正組成

    關係 宮位 分析重點
    對宮 福德宮 消費觀、金錢觀、精神追求對財運的影響
    三合 命宮 賺錢能力的個人基礎
    三合 事業宮 財富的主要來源渠道

    分析原則

    1. 福德宮化祿 → 財帛宮 → 精神富足帶動財富，投資眼光好
    2. 福德宮化忌 → 財帛宮 → 消費欲望失控、賭博傾向、財來財去
    3. 命宮 + 財帛宮 + 事業宮 皆有吉星 → 財官格局完整，一生財源穩定
    4. 財帛宮空宮借福德宮 → 財運隨心情起伏，需培養理財意識

    田宅宮：真正的財庫

    田宅宮不僅代表房產，也是財富儲蓄的宮位（財帛宮主流動，田宅宮主積累）：

    田宅宮狀態 對財富的影響
    田宅宮主星廟旺 + 化祿 財富能積累，有房產運
    田宅宮化忌 財難守，房產有變
    財帛宮化祿 沖 田宅宮（即化祿入子女宮） 賺得多但存不住
    財帛宮化祿 入 田宅宮 收入直接轉為儲蓄/房產

    輔煞星對事業財富的影響

    輔星

    輔星 入事業宮 入財帛宮
    左輔右弼 貴人助力、團隊佳、適合管理 貴人帶財、合夥運
    文昌文曲 文職有成、專業技能、考試升遷 因文才生財（寫作、教學、諮詢）
    天魁天鉞 職場長輩提攜、機遇多 貴人送財
    祿存 保守務實的職業發展 財富穩固、擅長儲蓄
    天馬 動態職業（業務、外派） 動中生財、變化中獲利

    祿馬交馳（祿存 + 天馬同宮或對照在事業/財帛）→ 財源廣進、動財大格局。

    煞星

    煞星 入事業宮 入財帛宮
    擎羊 職場競爭激烈、易犯小人 因財起爭、意外破財
    陀羅 事業拖延、進展緩慢 錢財拖欠難收、慢性漏財
    火星 事業起伏快、突發變動 突發之財或突發破財
    鈴星 暗中被排擠、暗損 暗中破財、被騙
    地空 事業方向虛無、想法不切實際 財來財去、投資失利
    地劫 事業被搶奪、被騙 明損、破財

    特殊組合

    • 空劫夾財帛 → 財難守，宜投資無形資產（技能、知識）
    • 羊陀夾事業 → 職場壓力大，宜穩守本業
    • 火貪 / 鈴貪 在事業或財帛 → 橫發格局，可能突發暴富但需防暴跌

    四化入事業宮 / 財帛宮

    化祿入

    位置 意義
    化祿入事業宮 事業順遂、業務擴張、有發展機會
    化祿入財帛宮 財源廣進、收入增加
    化祿入田宅宮 房產運佳、財能積累
    化祿入命宮 主觀順遂，工作機遇自來

    化權入

    位置 意義
    化權入事業宮 升遷、掌權、管理職
    化權入財帛宮 掌控財權、大進大出
    化權入命宮 主導能力強，領導型職業

    化科入

    位置 意義
    化科入事業宮 名譽提升、行業口碑
    化科入財帛宮 靠專業/名聲賺錢

    化忌入

    位置 意義 應對
    化忌入事業宮 事業阻礙、換工作、被降職 減少高風險決策、暫緩擴張
    化忌入財帛宮 破財、投資虧損、財務糾紛 保守理財、遠離高風險投資
    化忌入田宅宮 房產糾紛、資產縮水 不宜買賣不動產、注意合約
    化忌沖事業宮（即入夫妻宮） 婚姻/合夥人拖累事業 家庭事業需分明
    化忌沖財帛宮（即入福德宮） 消費欲望失控、投資決策失誤 控制花費、冷靜投資

    大限流年觸發規則

    事業高峰、財運爆發或破財危機的時機判斷。

    事業發展時機

    高峰指標：

    • 大限走到事業宮或財帛宮，且該宮主星廟旺 + 生年化祿/權/科
    • 大限四化的化祿入本命事業宮
    • 流年化權入本命事業宮 → 該年適合升遷、創業
    • 流年化科入命宮 → 該年適合考試、應聘、樹立名聲

    危機指標：

    • 大限化忌入本命事業宮 → 此十年職業變動大，宜守成
    • 流年化忌沖本命事業宮 → 該年宜低調、避免重大決策
    • 流年羊陀夾事業宮 → 該年職場鬥爭激烈

    財運爆發時機

    爆發指標：

    • 大限走到財帛宮，遇火星或鈴星（火貪/鈴貪橫發）
    • 大限化祿入財帛宮或田宅宮
    • 流年疊祿（本命 + 大限 + 流年三祿在同宮） → 該年重大財機

    破財指標：

    • 大限化忌入財帛宮
    • 流年化忌沖財帛宮
    • 流年遇「地空地劫入財帛」→ 大破財、投資失利
    • 疊忌在財帛宮 → 該年重大財務危機，宜遠離投資、慎重借貸

    事業與感情、健康的聯動

    • 事業宮化忌沖夫妻宮 → 事業壓力影響婚姻
    • 事業宮化忌沖疾厄宮（即入父母宮）→ 職業病、過勞
    • 財帛宮化忌沖福德宮 → 為財勞心，精神焦慮

    綜合分析要訣

    1. 先看格局層次（見 geju.md）：紫府朝垣、機月同梁、府相朝垣等格局決定事業財富的天花板
    2. 再看三方四正：不孤立看單宮
    3. 輔煞四化定細節：吉星旺相 vs 煞星衝破決定具體吉凶
    4. 大限流年定時機：什麼時候該進、什麼時候該守
    5. 建議具體化：避免「財運一般」等模糊表述，給出行業/時機/守進的具體方向
