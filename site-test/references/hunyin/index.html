    婚姻分析

    夫妻宮概述

    夫妻宮是紫微斗數中分析婚姻感情的主要宮位，代表配偶特質、婚姻狀況和感情模式。

    夫妻宮主星分析

    紫微在夫妻宮

    配偶特質： - 有地位、有能力 - 性格強勢、有主見 - 外貌端正大方

    婚姻狀況： - 配偶條件佳 - 可能晚婚 - 婚姻穩定

    注意事項： - 雙方都強勢可能衝突 - 需要互相尊重

    天機在夫妻宮

    配偶特質： - 聰明機智 - 善於謀劃 - 心思細膩

    婚姻狀況： - 感情多變 - 可能有波折 - 需要溝通

    太陽在夫妻宮

    配偶特質： - 熱心、光明 - 愛面子 - 忙碌勞碌

    婚姻狀況： - 配偶事業心重 - 聚少離多 - 男命尤佳

    武曲在夫妻宮

    配偶特質： - 務實、重財 - 性格剛硬 - 不善言辭

    婚姻狀況： - 物質條件佳 - 感情較冷淡 - 需要經營

    天同在夫妻宮

    配偶特質： - 溫和、隨和 - 懂得享受 - 較為依賴

    婚姻狀況： - 感情和諧 - 彼此溫馨 - 適合居家

    廉貞在夫妻宮

    配偶特質： - 聰明精明 - 感情豐富 - 複雜多變

    婚姻狀況： - 感情波折多 - 可能有是非 - 需要包容

    天府在夫妻宮

    配偶特質： - 穩重保守 - 重視面子 - 有財運

    婚姻狀況： - 婚姻穩定 - 物質有保障 - 長久之象

    太陰在夫妻宮

    配偶特質： - 溫柔內斂 - 情緒敏感 - 有氣質

    婚姻狀況： - 女命得賢夫 - 男命得賢妻 - 感情細膩

    貪狼在夫妻宮

    配偶特質： - 多才多藝 - 交際廣泛 - 桃花較重

    婚姻狀況： - 感情複雜 - 可能有第三者 - 需要謹慎

    巨門在夫妻宮

    配偶特質： - 口才好 - 較多疑 - 愛爭辯

    婚姻狀況： - 容易爭吵 - 口舌是非 - 需要溝通

    天相在夫妻宮

    配偶特質： - 隨和穩重 - 守規矩 - 善於輔佐

    婚姻狀況： - 婚姻平穩 - 配偶配合 - 相互扶持

    天梁在夫妻宮

    配偶特質： - 正直清高 - 年紀可能較大 - 喜歡說教

    婚姻狀況： - 婚姻穩定 - 配偶年長 - 受配偶照顧

    七殺在夫妻宮

    配偶特質： - 剛強獨立 - 有衝勁 - 個性強烈

    婚姻狀況： - 感情激烈 - 可能有衝突 - 聚少離多

    破軍在夫妻宮

    配偶特質： - 變動不安 - 喜歡挑戰 - 開創型

    婚姻狀況： - 婚姻多變 - 可能離婚 - 不穩定

    婚姻吉凶

    婚姻吉利條件

    1. 夫妻宮主星廟旺
    2. 有輔星入宮（左輔、右弼等）
    3. 有吉化入宮（化祿、化科等）
    4. 無煞星破壞
    5. 三方四正星曜佳

    婚姻不利條件

    1. 夫妻宮主星陷落
    2. 有煞星入宮（擎羊、陀羅等）
    3. 化忌入宮
    4. 桃花星過重（貪狼、廉貞等）
    5. 空宮無主星

    1. 大限夫妻宮吉
    2. 流年逢紅鸞、天喜
    3. 夫妻宮逢化祿、化科
    4. 太陽或太陰旺相

    不利婚姻運勢

    2. 流年逢煞星
    3. 夫妻宮化忌
    4. 桃花過旺

    婚姻建議

    早婚型

    • 夫妻宮星曜穩定
    • 無煞星破壞
    • 姻緣早現

    晚婚型

    • 夫妻宮有煞星
    • 化忌入宮
    • 事業型命格

    謹慎型

    • 夫妻宮複雜
    • 桃花過重
    • 需慎選對象
