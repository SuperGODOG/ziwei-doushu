    十四主星詳解

    主星概述

    紫微斗數共有十四顆主星，分為北斗（7顆）、南斗（6顆）和中天（1顆）。主星決定命盤的基本格局和性格特質。

    北斗主星

    紫微星

    基本資料 - 五行：己土（陰土） - 別稱：帝星、北極星 - 主事：官祿、權威

    性格特質 - 高貴氣質、領導能力 - 自尊心強、不甘居人下 - 喜歡受人尊敬 - 有主見、有魄力

    優點 - 大器、有格局 - 領導能力強 - 胸襟開闘 - 有責任感

    缺點 - 高傲、自視甚高 - 不易認錯 - 好面子 - 可能孤獨

    廟旺：子、午 陷落：卯、酉

    與其他星同宮 | 同宮星 | 組合特點 | |--------|----------| | 天府 | 紫府同宮，大富大貴 | | 貪狼 | 紫貪，桃花重但有格局 | | 天相 | 紫相，穩重有權 | | 七殺 | 紫殺，權威強勢 | | 破軍 | 紫破，變動中有權 |

    天機星

    基本資料 - 五行：乙木（陰木） - 別稱：智慧星、謀略星 - 主事：謀略、變動

    性格特質 - 聰明機智 - 善於謀劃 - 心思細膩 - 好動不安定

    優點 - 聰明、反應快 - 善於分析 - 口才好 - 適應力強

    缺點 - 優柔寡斷 - 想太多 - 不夠穩重 - 易變心

    廟旺：丑、卯、巳、酉 陷落：辰

    與其他星同宮 | 同宮星 | 組合特點 | |--------|----------| | 太陰 | 機月，聰明細膩 | | 天梁 | 機梁，善於規劃 | | 巨門 | 機巨，口才辯論 |

    太陽星

    基本資料 - 五行：丙火（陽火） - 別稱：日星、官祿星 - 主事：光明、男性

    性格特質 - 光明磊落 - 熱心助人 - 愛面子 - 博愛無私

    優點 - 正直、光明 - 熱心公益 - 有號召力 - 樂觀積極

    缺點 - 過於理想化 - 愛管閒事 - 不夠務實 - 勞碌命

    廟旺：卯、辰、巳、午 陷落：酉、戌、亥

    特性：太陽在午宮最旺（日麗中天），在子宮最弱（日落西山）

    與其他星同宮 | 同宮星 | 組合特點 | |--------|----------| | 太陰 | 日月同輝，陰陽調和 | | 天梁 | 陽梁，正直清高 | | 巨門 | 日巨，是非口舌 |

    武曲星

    基本資料 - 五行：庚金（陽金） - 別稱：財星、將星 - 主事：財富、剛毅

    性格特質 - 剛毅果斷 - 重視財富 - 做事直接 - 不善言辭

    優點 - 執行力強 - 善於理財 - 意志堅定 - 實際務實

    缺點 - 過於強硬 - 不夠圓滑 - 較孤僻 - 缺少情趣

    廟旺：辰、戌、丑、未 陷落：卯

    與其他星同宮 | 同宮星 | 組合特點 | |--------|----------| | 天府 | 武府，財源廣進 | | 貪狼 | 武貪，創業發財 | | 天相 | 武相，財權並重 | | 七殺 | 武殺，剛毅非凡 | | 破軍 | 武破，財來財去 |

    天同星

    基本資料 - 五行：壬水（陽水） - 別稱：福星、解厄星 - 主事：福氣、享受

    性格特質 - 溫和善良 - 享受生活 - 隨遇而安 - 容易滿足

    優點 - 好相處 - 知足常樂 - 有福氣 - 人緣好

    缺點 - 懶散 - 缺乏進取心 - 意志不堅 - 依賴性強

    廟旺：子、午、卯、酉 陷落：巳、亥

    與其他星同宮 | 同宮星 | 組合特點 | |--------|----------| | 太陰 | 同陰，有福但懶 | | 天梁 | 同梁，遇難呈祥 | | 巨門 | 同巨，口舌是非 |

    廉貞星

    基本資料 - 五行：丁火（陰火） - 別稱：囚星、桃花星 - 主事：感情、是非

    性格特質 - 聰明精明 - 感情豐富 - 愛恨分明 - 複雜多變

    優點 - 聰明能幹 - 感情真摯 - 有魅力 - 適應力強

    缺點 - 是非多 - 感情複雜 - 容易招惹麻煩 - 情緒化

    廟旺：寅、申 陷落：卯、酉

    與其他星同宮 | 同宮星 | 組合特點 | |--------|----------| | 天府 | 廉府，穩重有權 | | 貪狼 | 廉貪，桃花重 | | 天相 | 廉相，行政能力 | | 七殺 | 廉殺，剛烈是非 | | 破軍 | 廉破，變動是非 |

    貪狼星

    基本資料 - 五行：甲木/壬水 - 別稱：桃花星、才藝星 - 主事：欲望、才藝

    性格特質 - 多才多藝 - 欲望強烈 - 魅力十足 - 善於交際

    優點 - 才藝出眾 - 交際能力強 - 多方面發展 - 有魅力

    缺點 - 欲望過多 - 容易沉迷 - 不夠專一 - 桃花過重

    廟旺：辰、戌、丑、未 陷落：寅

    南斗主星

    天府星

    基本資料 - 五行：戊土（陽土） - 別稱：財庫星、令星 - 主事：財富、穩定

    性格特質 - 穩重保守 - 重視財富 - 講究面子 - 守信用

    優點 - 穩重可靠 - 善於守成 - 信用好 - 有財運

    缺點 - 過於保守 - 不夠積極 - 有時固執 - 愛面子

    廟旺：全部宮位皆廟旺

    太陰星

    基本資料 - 五行：癸水（陰水） - 別稱：月星、財星 - 主事：財富、女性

    性格特質 - 溫柔細膩 - 情緒敏感 - 愛美 - 內斂含蓄

    優點 - 細心體貼 - 有氣質 - 有審美觀 - 耐心好

    缺點 - 過於敏感 - 情緒化 - 優柔寡斷 - 多愁善感

    廟旺：酉、戌、亥 陷落：卯、辰、巳

    特性：太陰在亥宮最旺（月朗天門），在巳宮最弱

    天相星

    基本資料 - 五行：壬水 - 別稱：印星、宰相星 - 主事：輔佐、印信

    性格特質 - 隨和輔佐 - 守規矩 - 有信用 - 善於協調

    優點 - 穩重守成 - 善於輔佐 - 講信用 - 有協調能力

    缺點 - 缺乏主見 - 過於服從 - 不夠積極 - 依賴性強

    廟旺：全部宮位 特性：天相受夾宮影響很大

    天梁星

    基本資料 - 五行：戊土 - 別稱：蔭星、解厄星 - 主事：蔭護、清高

    性格特質 - 正直清高 - 喜歡助人 - 年長者緣佳 - 有道德感

    優點 - 正直可靠 - 樂於助人 - 有長輩緣 - 解厄能力

    缺點 - 過於清高 - 愛說教 - 有時固執 - 較孤僻

    廟旺：子、卯、午、酉 陷落：巳、亥

    七殺星

    基本資料 - 五行：庚金 - 別稱：將星、孤星 - 主事：開創、權威

    性格特質 - 剛強果決 - 獨立自主 - 有衝勁 - 不畏艱難

    優點 - 開創能力強 - 執行力佳 - 有魄力 - 獨立性強

    缺點 - 過於強勢 - 孤獨傾向 - 不夠圓滑 - 容易衝動

    廟旺：寅、申、子、午 陷落：卯、酉

    破軍星

    基本資料 - 五行：癸水 - 別稱：耗星、先鋒星 - 主事：破壞、變動

    性格特質 - 開創破壞 - 追求變動 - 不安於現狀 - 喜歡挑戰

    優點 - 開創能力強 - 勇於突破 - 不怕困難 - 有衝勁

    缺點 - 破壞力強 - 不夠穩定 - 浪費傾向 - 人際關係差

    廟旺：子、午 陷落：卯、酉

    巨門星

    基本資料 - 五行：癸水 - 別稱：暗星、口舌星 - 主事：口舌、是非

    性格特質 - 口才很好 - 善於辯論 - 多疑心重 - 是非較多

    優點 - 口才出眾 - 分析能力強 - 直言不諱 - 專業知識強

    缺點 - 是非多 - 疑心重 - 容易衝突 - 人際關係差

    廟旺：辰、戌、丑、未 陷落：子
