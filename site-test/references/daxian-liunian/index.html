    大限流年推算

    大限概述

    大限是紫微斗數中十年一運的運勢週期，代表人生各階段的運勢走向。

    大限計算

    起運規則

    大限的起始年齡由五行局決定：

    五行局 起運年齡
    水二局 2歲
    木三局 3歲
    金四局 4歲
    土五局 5歲
    火六局 6歲

    順逆規則

    條件 排法
    陽年男 順行
    陽年女 逆行
    陰年男 逆行
    陰年女 順行

    陽年：甲、丙、戊、庚、壬年 陰年：乙、丁、己、辛、癸年

    大限宮位

    從命宮開始，每十年走一個宮位：

    大限 年齡段（以土五局為例）
    第一大限 5-14歲
    第二大限 15-24歲
    第三大限 25-34歲
    第四大限 35-44歲
    第五大限 45-54歲
    第六大限 55-64歲
    第七大限 65-74歲
    第八大限 75-84歲

    大限分析

    看大限宮位

    1. 大限命宮：大限走到的宮位
    2. 大限主星：該宮位的主星
    3. 大限輔煞：該宮位的輔星和煞星
    4. 大限四化：大限天干產生的四化

    大限天干（五虎遁宮干對照）

    大限四化由大限宮位的宮干產生，而宮干由生年天干按「五虎遁」推算：從寅宮起正月，順排天干至各宮。

    五虎遁口訣：

    • 甲己之年丙作首（寅宮起丙）
    • 乙庚之年戊為頭（寅宮起戊）
    • 丙辛必定尋庚起（寅宮起庚）
    • 丁壬壬位順行流（寅宮起壬）
    • 戊癸何方發甲寅（寅宮起甲）

    完整宮干對照表：

    生年干 寅宮 卯宮 辰宮 巳宮 午宮 未宮 申宮 酉宮 戌宮 亥宮 子宮 丑宮
    甲、己 丙 丁 戊 己 庚 辛 壬 癸 甲 乙 丙 丁
    乙、庚 戊 己 庚 辛 壬 癸 甲 乙 丙 丁 戊 己
    丙、辛 庚 辛 壬 癸 甲 乙 丙 丁 戊 己 庚 辛
    丁、壬 壬 癸 甲 乙 丙 丁 戊 己 庚 辛 壬 癸
    戊、癸 甲 乙 丙 丁 戊 己 庚 辛 壬 癸 甲 乙

    使用步驟：

    1. 找出當前大限所在的宮位地支
    2. 查上表，按生年干取該地支對應的宮干
    3. 該宮干對應的四化（見 sihua.md 天干四化表）即為此大限四化
    4. 大限四化與本命四化並用：本命四化定基調，大限四化定十年動態

    示例：生年甲，當前大限走到午宮 → 查表，甲己組午宮宮干為「庚」→ 庚干四化為「太陽化祿、武曲化權、太陰化科、天同化忌」→ 此大限太陽落宮受化祿加持，天同落宮受化忌沖擊。

    大限三方四正

    分析大限命宮的三方四正： - 大限財帛宮 - 大限事業宮 - 大限遷移宮

    大限吉凶判斷

    吉利大限

    條件 意義
    主星廟旺 運勢佳
    輔星入宮 有貴人
    化祿入宮 財運好
    化權入宮 有權力
    化科入宮 有名聲
    無煞星 順遂

    不利大限

    條件 意義
    主星陷落 運勢差
    煞星入宮 有阻礙
    化忌入宮 有困難
    空宮無星 虛弱

    流年推算

    流年命宮

    流年命宮 = 太歲所在宮位

    例如： - 子年：流年命宮在子宮 - 丑年：流年命宮在丑宮 - ...

    流年十二宮

    從流年命宮開始，逆時針排列十二宮： - 流年命宮 - 流年兄弟宮 - 流年夫妻宮 - ...

    流年四化

    流年天干確定方法：流年天干由當年農曆年份對應的年干決定（60 甲子循環，每 10 年天干循環一次）。判定分界為農曆正月初一（部分派別以立春為界，本 skill 統一以農曆正月初一）。

    近年天干對照（供快速查閱）：

    公曆年 農曆年干支 流年天干
    2020 庚子 庚
    2021 辛丑 辛
    2022 壬寅 壬
    2023 癸卯 癸
    2024 甲辰 甲
    2025 乙巳 乙
    2026 丙午 丙
    2027 丁未 丁
    2028 戊申 戊
    2029 己酉 己

    甲 廉貞 破軍 武曲 太陽
    乙 天機 天梁 紫微 太陰

    戊 貪狼 太陰 右弼 天機

    三層四化疊加規則：

    一顆星曜同時可承受三層四化（生年、大限、流年），力量疊加：

    疊加類型 意義 影響程度
    疊祿（本命 + 大限 + 流年皆化祿在同星） 極旺之運，機會高峰 重大吉利
    疊權 權力全開，主導能力極強 重大吉利
    疊科 名聲鼎盛 重大吉利
    疊忌（本命化忌 + 大限化忌 + 流年化忌在同宮/同星） 問題爆發，禍不單行 重大凶險
    祿忌交會（一層化祿、另一層化忌到同星或對宮） 因財致禍或有得有失 需具體分析宮位

    分析優先級：本命四化 > 大限四化 > 流年四化。本命四化定一生基調，大限修正十年走向，流年觸發具體事件。

    小限推算

    小限定義

    小限是紫微斗數中每年一宮的運勢週期。

    小限起點

    從命宮開始，每年走一宮： - 男命順行 - 女命逆行

    小限與流年

    小限與流年都代表當年運勢，需結合分析。

    流月流日

    流月

    流月 = 流年的月份運勢 - 正月：流月命宮在流年命宮 - 依次排列...

    流日

    流日 = 當日的運勢 - 初一：流日命宮在流月命宮 - 依次排列...

    運勢預測要點

    綜合分析

    1. 本命：基本格局
    2. 大限：十年趨勢
    3. 流年：當年運勢
    4. 流月：月運（可選）

    吉凶判斷

    1. 看星曜配置
    2. 看四化入宮
    3. 看煞星影響
    4. 看格局高低

    建議方式

    1. 順應運勢
    2. 趨吉避凶
    3. 把握機會
    4. 主動應對

    身宮

    身宮代表後天運勢，影響中晚年（約 40 歲後）的生活。命宮為先天，身宮為後天——命宮決定本質，身宮體現後天努力方向與人生追求。

    身宮定位

    身宮沒有獨立宮位，依附於六個宮位之一（由出生時辰決定）：

    出生時辰 身宮所在 特點
    子、午時 命宮（身命同宮） 主觀意識強，一生辛勞，命運大起大落
    丑、未時 福德宮 重精神享受，懂生活品味；星好則享福，不好則多煩惱
    寅、申時 事業宮 事業心強，重榮譽成就；適合創業，易忽略家庭
    卯、酉時 遷移宮 喜外出變動，適應力強；適合異地發展，人際活躍
    辰、戌時 財帛宮 重金錢物質，有經濟頭腦；適合經商，易為財奔波
    巳、亥時 夫妻宮 重感情家庭，對婚姻敏感；配偶影響大，需謹慎擇偶

    命身合參

    命宮 身宮 命運走向
    好 好 富貴雙全，一生吉利
    好 不好 早年順遂，中晚年財源不聚
    不好 好 早年艱辛，白手起家，中晚年發福
    不好 不好 一生坎坷，成就有限

    身宮所在宮位會放大該宮位的吉凶程度。例如身宮在財帛宮，則財運對命主影響更大；身宮在夫妻宮，則感情婚姻成為人生重心。
