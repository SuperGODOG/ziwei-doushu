    十二宮位詳解

    宮位概述

    紫微斗數以十二宮位為基本框架，每個宮位代表人生的不同面向。十二宮位以命宮為起點，逆時針排列。

    命宮

    基本含義

    命宮是整個命盤的核心，代表命主本人的一切：

    • 個性特質：天生的性格傾向
    • 人生格局：一生的基本格局高低
    • 行為模式：處事風格與習慣
    • 外貌氣質：外在形象與氣場

    分析重點

    1. 命宮主星決定基本性格
    2. 命宮輔煞星影響格局高低
    3. 命宮四化決定人生起伏
    4. 三方四正星曜影響整體運勢

    太陽 光明磊落、熱心、愛面子

    兄弟宮

    基本含義

    • 兄弟姐妹：手足關係
    • 同輩朋友：平輩的人際關係
    • 合作夥伴：同事、合夥人
    • 母親身體：部分派別認為

    分析重點

    1. 兄弟數量與緣分
    2. 手足之間的關係
    3. 是否能得到手足幫助
    4. 與同事的相處模式

    • 婚姻關係：夫妻相處模式
    • 感情狀態：戀愛、婚姻的品質
    • 異性緣分：與異性的互動

    分析重點

    1. 配偶的性格特質
    2. 婚姻的穩定性
    3. 夫妻的相處模式
    4. 適婚年齡與姻緣時機

    • 對宮：相互影響、互為表裡
    • 三合宮：力量相加、互相支援
    • 夾宮：夾制作用、影響本宮

    空宮借對規則

    空宮指該宮沒有十四主星坐守（輔星、煞星存在時仍算空宮）。紫微斗數中空宮極為常見，本身不代表吉凶。

    空宮分析四步法

    第一步：先看空宮內部 — 空宮內的輔星、煞星、雜曜仍然重要，不可忽略。 第二步：借對宮主星 — 將對宮主星借入分析。太陽、太陰等「亮星」借入約有八九成力量，其他星曜約六七成。 第三步：三方四正 — 空宮本無吉凶，完全取決於三方四正的組合。組合好則大吉，組合差則大凶。 第四步：兩夾影響 — 空宮被煞星（地空、地劫等）所夾時，影響加劇。

    各宮空宮含義

    • 命宮空宮：性格較無固定模式，易受外界影響。借遷移宮主星分析，三方四正好仍為吉格。
    • 夫妻宮空宮：對感情隨緣，多參考事業宮主星。
    • 財帛宮空宮：借福德宮主星分析，忌化忌衝破。
    • 疾厄宮空宮：若三方四正好，反而身體健康（無特定偏差）。
    • 田宅宮空宮：借子女宮主星分析，有化祿、祿存仍主吉。

    夾宮分析

    夾宮指左右兩鄰宮的星曜對中間宮位施加無形影響。夾宮作用不如三方四正強烈，但無形中深刻影響命主境遇。

    吉星夾

    魁鉞夾：天魁、天鉞分居左右鄰宮（固定夾辰、戌二宮）。主得長輩貴人暗中提攜，不貴即當大富。魁鉞永不****同宮。

    昌曲夾：文昌、文曲分居左右。主文采、學業有成。昌曲不能落陷。

    輔弼夾：左輔、右弼分居左右。主助力強大、貴人多。

    祿權科夾：化祿/化權/化科在左右鄰宮。主福報加成。

    凶星夾

    羊陀夾：擎羊、陀羅分居左右。祿存坐命時必形成羊陀夾命。主保守謹慎、壓力沉重。若命宮主星廟旺有吉星，反為吉（壓力成助力）。若見空劫破祿，易走極端。

    火鈴夾：火星、鈴星分居左右（寅午戌年生人）。主被動反擊、內心急切。最忌夾太陰或天相，易偏離正軌。

    空劫夾：地空、地劫分居左右。主虛耗損失、財運不佳。從事藝術、宗教或精神層面發展可化解。

    夾宮通用原則

    1. 吉星夾：三個宮位不能有凶星，有忌星則不算夾
    2. 凶星夾：中間宮位有凶星才算夾
    3. 天相最重夾宮：羊陀夾、火鈴夾、空劫夾皆不吉；最喜巨門化祿來夾（財蔭夾印）
    4. 所有吉格遇煞星夾均為破格，秀而不實，福澤有損
