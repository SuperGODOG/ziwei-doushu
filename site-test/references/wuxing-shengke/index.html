    五行生克分析方法

    紫微斗數中星曜各有五行屬性，同宮或三方星曜間的五行生克關係直接影響星曜表現強弱。

    星曜五行屬性速查

    十四主星

    五行 星曜
    金 武曲、七殺
    木 天機、貪狼（亦帶水）
    水 天同、太陰、天相、破軍、巨門
    火 太陽、廉貞、天馬
    土 紫微、天府、天梁

    輔星煞星

    五行 星曜
    金 擎羊、文昌
    木 —
    水 文曲、右弼、地空、地劫
    火 火星、鈴星、天魁
    土 左輔、天鉞、陀羅

    地支五行

    五行 地支
    金 申、酉
    木 寅、卯
    水 亥、子
    火 巳、午
    土 辰、戌、丑、未

    五行生克關係

    相生

    木生火 → 火生土 → 土生金 → 金生水 → 水生木

    相克

    木克土 → 土克水 → 水克火 → 火克金 → 金克木

    陰陽有情與無情

    • 陰克陽為有情之克：克中帶生化。如廉貞（陰火）入申宮（陽金），反成「雄宿朝元格」，主文采聲譽
    • 陽克陽為無情之克：克制較重。如太陽（陽火）克武曲（陽金），武曲受制明顯
    • 陰克陰、陽克陰：力量居中

    同宮星曜互動分析

    星與星生克

    相生則相互增強，相剋則一方受制。

    實例： - 武曲（金）+ 火星（火）→ 火克金，武曲能量被壓制。若得土星通關（火生土、土生金），則化克為生 - 武曲（金）+ 七殺（金）→ 同五行，氣味相投，相互增強 - 破軍（陰水）+ 火星（陽火）→ 水中帶火，水火既濟，反而有利 - 太陽（火）+ 擎羊（金）→ 夏季火旺金死，太陽可制服煞星

    星與宮生克

    關係 效果
    宮生星 星力增強（如木宮生火星）
    星生宮 洩氣減力
    宮克星 受制無力（如午火宮剋七殺金）
    星克宮 耗氣不善

    通關救應

    當兩星相剋時，若有第三星居中調和形成連續相生，則化克為生：

    火（克）金 → 若得土 → 火生土、土生金 → 化克為生，被克者反而增力

    例如：七殺（金）坐午宮（火），火克金不利。若三方有紫微（土）或天府（土），則火生土、土生金，通關化解。

    四季旺衰對五行的影響

    季節 旺 相 休 囚 死
    春 木 火 水 金 土
    夏 火 土 木 水 金
    秋 金 水 土 火 木
    冬 水 木 金 土 火
    四季末 土 金 火 木 水

    應用：夏季火旺金死，火星鈴星能量最強，武曲七殺能量最弱；秋季金旺木死，武曲七殺最強，天機貪狼最弱。

    五行生克在格局中的應用

    1. 命宮星曜組合：先看主星五行生克，再看與輔煞星的生克
    2. 三方四正：對宮力量佔 50%，三合宮各佔 25%，五行生克按此比例加權
    3. 四化改性：化祿增力、化忌減力會影響五行平衡
    4. 行運變化：大限流年星曜加入後，五行力量對比隨之改變

    五行生克不是絕對的——需結合廟旺陷落、四化、陰陽有情無情等因素綜合判斷。單一克殺在通關救應下可轉化為助力。

    五行局詳解

    五行局由「命宮天干 + 地支」的納音五行決定，是紫微斗數的核心背景參數：

    1. 決定紫微星位置（見 daxian-liunian.md 或排盤工具）
    2. 決定起運年齡
    3. 象徵命主先天氣質類型
    五行局 起運年齡 象徵氣質 命主特質傾向
    水二局 2 歲起運 智慧、流動、變化 聰明善變、適應力強、情感細膩、善於溝通
    木三局 3 歲起運 生長、仁厚、發展 溫和有耐心、注重成長、有規劃能力
    金四局 4 歲起運 剛毅、決斷、收斂 果斷務實、意志堅定、善於執行、較固執
    土五局 5 歲起運 穩重、包容、厚實 穩健可靠、重視根基、發展緩但持久
    火六局 6 歲起運 熱情、光明、快速 積極熱情、行動迅速、易衝動、爆發力強

    五行局與命宮主星的配合

    • 五行局生命宮主星 → 先天氣質支撐命宮，格局加分（如水二局+木類主星，水生木）
    • 五行局克命宮主星 → 先天氣質壓制命宮，需靠後天努力（如金四局+木類主星，金克木）
    • 命宮主星克五行局 → 命宮強勢消耗先天能量，早年勞碌
    • 五行局與命宮主星同五行 → 氣質純正，格局最穩定

    五行局與起運的深層意義

    起運越晚（如火六局 6 歲），代表童年運勢由父母宮主導，個人運勢起步較晚；起運越早（如水二局 2 歲），個人運勢介入早，童年即顯性格特色。

    五行反侮

    當克方力量不足、被克方力量過強時，被克方反而制克方——稱為「反侮」。

    判斷標準： - 廟旺 + 吉星輔助 → 力量強 - 陷落 + 煞星衝破 → 力量弱

    典型情境：

    常態關係 反侮條件 反侮效果
    金克木 陷落武曲（金）遇廟旺貪狼（木） 木反侮金，武曲功能受損、貪狼欲望反噬武曲
    木克土 陷落天機（木）遇廟旺紫微天府（土） 土反侮木，天機謀略難施
    水克火 陷落破軍（水）遇廟旺太陽（火） 火反侮水，破軍破壞力被日光壓制
    火克金 陷落廉貞（火）遇廟旺武曲七殺（金） 金反侮火，廉貞火焰不足以熔煉大金
    土克水 陷落天梁（土）遇廟旺太陰（水） 水反侮土，天梁蔭力被太陰吸走

    反侮判斷需綜合廟旺陷落與輔煞四化，不是機械應用。

    五行流通與命盤整體觀

    紫微斗數不僅看單宮五行，還看整個命盤十二宮的五行氣脈是否順暢流通。

    流通格局（吉）

    十二宮主星形成連續相生鏈，氣運周流不息：

    木生火 → 火生土 → 土生金 → 金生水 → 水生木（回到起點）

    判斷： - 命宮 → 財帛宮 → 官祿宮 三方相生 → 財官事業一氣呵成 - 三方四正皆為相生關係 → 大格局

    阻塞格局（凶）

    某環節斷裂或反克過重，氣運卡在某宮無法流出。

    典型阻塞： - 命宮（火）→ 財帛宮（水）→ 水克火，火無以生土，財來反傷身 - 官祿宮（金）→ 命宮（木）→ 金克木，事業壓制個人發展

    化解思路

    1. 通關：若三方四正有中間五行星曜，可通關化解（如火克金卡點，若有土星則火生土、土生金）
    2. 借助行運：大限或流年帶入的四化與新星曜可改變五行力量對比
    3. 職業選擇：從事化解五行的行業（如命宮火太旺，從事水性行業如金融、水利、貿易等）

    綜合分析案例

    案例一：金四局命宮武曲七殺

    • 五行局（金）+ 命宮主星（金）→ 同五行純氣，格局穩定
    • 若午宮（火）為命宮 → 火克金，先天壓力大，需通關（土星）
    • 若酉宮（金）為命宮 → 金氣加倍，過剛易折，宜配陰柔輔星（左輔、天鉞）

    案例二：水二局命宮太陽廟旺

    • 五行局（水）克命宮（火）→ 先天氣質與命宮相克，需三方有木星（天機、貪狼）通關（水生木、木生火）
    • 若無通關 → 童年運勢與個性磨合期較長，太陽的光明特質受壓

    案例三：火六局命宮天梁

    • 五行局（火）生命宮（土）→ 先天氣質支撐命宮，穩健有力
    • 天梁的蔭護能力被火局激活 → 適合早年即從事有社會責任感的工作

    案例分析需結合完整命盤，包括四化、大限、輔煞。此處僅示範五行分析的思路。
