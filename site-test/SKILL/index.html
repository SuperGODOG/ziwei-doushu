    紫微斗數解盤技能 (Zi Wei Dou Shu Chart Reading Skill)

    紫微斗數是以出生年月日時排列星盤、分析十二宮位星曜組合來推算命運的星命學系統。本技能聚焦於已排好命盤後的解讀分析，排盤由用戶自行完成。

    技能結構

    /ziwei-doushu/
├── SKILL.md                    ← 本文件：工作流 + 路由 + 輸出模板（流程指令，不含參考數據）
└── references/                 ← 權威數據層（解盤時按需讀取）
    ├── shier-gong.md              十二宮位詳解（含空宮處理規則）
    ├── shisi-zhuixing.md          十四主星詳解（含五行、亮度、廟旺陷落）
    ├── fuzhu-xing.md              輔星助星詳解
    ├── sha-xing.md                煞星詳解
    ├── sihua.md                   四化飛星詳解（含天干四化表）
    ├── geju.md                    格局分析（吉格/凶格/條件/純度判定）
    ├── daxian-liunian.md          大限流年推算方法
    ├── hunyin.md                  婚姻感情專題
    ├── shiye-caifu.md             事業財富專題
    ├── jiankang.md                健康專題
    ├── heluo-guaxiang.md          河洛卦象分析方法

    ├── wuxing-shengke.md          五行生克分析方法
    └── xingqing-mingli.md         星情論與名人命例

    排盤由用戶使用外部工具完成（如 iztro 或任意在線排盤網站），本 skill 只做解盤。

    資料來源規則（HARD-GATE）

    SKILL.md 僅包含工作流程與路由指令。所有星曜屬性、宮位含義、格局條件、四化規則等具體數據，必須從 references/ 對應文件中按需讀取。本文件不內聯任何參考數據表格。

    每次回答用戶前，必須先讀取與問題相關的所有 reference 文件。不讀不答。

    防止繞過（Red Flags）

    以下想法出現任何一條，都意味著你在繞過規則。STOP，去讀 reference。

    繞過藉口 實際情況
    「這顆星的屬性我訓練數據裡有」 訓練數據可能錯誤或與本 skill 的 reference 衝突。去讀。
    「問題太簡單，不用讀 reference」 簡單問題最容易因憑記憶而給出似是而非的答案。去讀。
    「用戶只問了一顆星，不需要讀完整文件」 一顆星的分析依賴其廟旺陷落、亮度、同宮組合，都需要 reference 數據。去讀。
    「我已經在前面讀過這個文件了」 新問題可能需要文件中不同的段落。重新確認。
    「前面幾步已經分析過了，後面的步驟可以簡化」 每一步有獨立的完成標準，簡化等於跳步。
    「輔助流派沒有 reference，跳過就好」 正確——輔助流派如果無數據支撐，確實應跳過，不要編造。
    「用戶只給了部分命盤，我只能憑推測分析」 不能。缺失關鍵宮位應告知用戶補齊。

    使用時機

    • 用戶提供命盤數據並請求解讀分析
    • 用戶詢問星曜特性、宮位含義、格局、四化、大限流年
    • 關鍵詞觸發：「紫微斗數」「命盤」「解盤」「十二宮」「四化」「大限」「流年」

    排盤由用戶完成。 若用戶尚未排盤，引導其使用外部排盤工具（推薦 iztro 或任意在線排盤網站）自行排盤後再來。

    用戶引導（多輪對話模式）

    第一輪：用戶發起

    先確認用戶是否已有命盤數據：

    「請提供排好的命盤數據，格式參考如下：」

    命宮：[地支宮位]，主星：[星曜列表]，輔星：[如有]，煞星：[如有]，四化：[如有]
兄弟宮：[地支宮位]，主星：[星曜列表]，...
夫妻宮、子女宮、財帛宮、疾厄宮、遷移宮、交友宮、事業宮、田宅宮、福德宮、父母宮（同上格式）

生年四化：化祿在[宮位]，化權在[宮位]，化科在[宮位]，化忌在[宮位]
當前大限：[宮位]，虛歲 [X]-[Y]

    「如果還沒排盤，可用 iztro 或任意在線排盤網站，把結果按上述格式貼過來。」

    防範記憶污染（ANTI-CONTAMINATION）

    在具有持久記憶的 Agent 環境中（如 Hermes），系統可能自動將歷史對話中的命盤數據注入新會話。嚴禁使用任何來自系統記憶的命盤數據。 分析必須只基於當前對話中用戶直接提供的命盤。如果當前對話中沒有由用戶提供的完整命盤，要求用戶提供——即使記憶中似乎有數據。

    命盤不完整時的處理

    如果用戶只提供了部分宮位，根據問題判斷：

    • 問題涉及的關鍵宮位齊全 + 命宮三方四正齊全 → 可基於現有數據分析，但告知用戶「基於部分數據，分析可能不完整」
    • 命宮或與問題直接相關的宮位缺失 → 要求用戶補充：「要分析[問題]，需要[缺失宮位]的數據，請補充後我來分析」

    第二輪：接收命盤 + 聚焦問題

    收到命盤數據後，確認命盤結構，然後引導聚焦：

    「命盤已收到。你想了解哪些方面？可以直接告訴我具體問題，比如『今年能換工作嗎』『我的感情運如何』『幫我分析整體格局』。」

    後續輪次

    每次以一個核心問題為主軸。若子問題與主問題共享同一套分析數據（如「夫妻宮破軍是不是婚姻不好，什麼時候能好轉」），可一併處理。

    分析完後結尾：

    「還有其他想了解的嗎？」

    用戶問到 references 未涵蓋的概念時

    如果用戶問的概念在 references/ 中沒有對應文件或章節：

    1. 先檢查是否在已有文件的非顯眼位置（如「五行局」可能在 daxian-liunian.md 的起運規則中提及）
    2. 如果 references 確實沒有，坦誠告知：「這個概念在目前的參考資料中沒有詳細說明，以下是我基於紫微斗數通則的理解：[簡要回答]。如果需要更深入的分析，建議查閱專門的[概念名]資料。」
    3. 不要編造——寧可說「資料不足」也不要憑訓練數據生成看似權威的內容

*聲明：紫微斗數命盤僅供參考。*

    模式選擇規則

    問題類型 使用模式
    「今年能換工作嗎」「什麼時候結婚」「財運如何」 Short Mode
    「我的婚姻好不好」──單一領域的深度分析 Short Mode（僅展開所問宮位的三方四正，最多一個宮位）
    「幫我分析整體格局」「全面解盤」 Full Mode
    「事業不順是否影響婚姻」──跨領域 Full Mode
    「我命宮XX，幫我看看」──聚焦命宮 Short Mode

    不確定時，默認用 Short Mode。用戶可以隨時要求更詳細的分析。

    解盤工作流程（五步）

    Short Mode 中不必全部展開，但思考時按此順序過一遍。Full Mode 中必須嚴格執行每一步。

    第一步：命宮三方四正分析

    三合派的核心是三方四正一體觀察：

    1. 命宮本宮 □ — 主星組合、廟旺陷落、是否有煞星同宮、是否有四化
    2. 財帛宮 □ — 財星配置、對三方四正的影響
    3. 官祿宮 □ — 事業星曜、職業適性
    4. 遷移宮 □ — 外在表現、人際關係
    5. 三方四正整體評價 □ — 格局層次、發展潛力

    若命宮為空宮（無主星）：借對宮遷移宮星曜分析，並標註「命宮空宮，借遷移宮[星曜]」。空宮在紫微斗數中常見，不代表格局差，但命主性格受遷移宮主星主導。 若三方宮位有空宮：同樣借對宮星曜。分析時注明哪個宮位為空、借用了哪顆星。

    → 讀取 references/shisi-zhuixing.md 獲取各主星的廟旺陷落與特性 → 讀取 references/shier-gong.md 理解各宮位分析重點及空宮借對規則 → 讀取 references/sihua.md 查看各宮是否有四化

    第二步：星曜綜合互動

    將同一宮位內所有星曜作為整體看待：

    1. 主星為體 □ — 五行屬性、本質特性、廟旺陷落
    2. 吉星加會為助 □ — 六吉星（左輔右弼文昌文曲天魁天鉞）的增強效應
    3. 煞星衝破為阻 □ — 六煞星（擎羊陀羅火星鈴星地空地劫）的削弱效應
    4. 四化為變 □ — 化祿/化權/化科/化忌對主星的表現方向改造
    5. 星曜組合 □ — 同宮星的交互效應（注意五行生克：如火克金、金克木，影響星曜表現）
    6. 夾宮效應 □ — 檢查命宮及其他關鍵宮位的兩鄰宮星曜（如魁鉞夾命為貴、羊陀夾命為困）

    → 讀取 references/fuzhu-xing.md 和 references/sha-xing.md

    第三步：格局三層評定

    1. 格局類型 □ — 是否形成傳統格局？（參考 references/geju.md 中的格局列表）
    2. 格局等級 □ — 上格/中格/下格
    3. 若 reference 未明確標註某格局的等級，基於以下原則推斷：主星廟旺+吉星輔助+無煞星衝破為上格，主星平+部分吉星+少量煞星為中格，主星陷落+煞星多+格局條件不完整為下格
    4. 格局純度 □ — 完整形成/部分形成/破格。檢查：格局條件是否全部滿足？有無煞星衝破？有無吉星加護？破格因素影響程度（輕微：有一煞星但不破壞格局主體 / 中等：兩煞星或煞星在關鍵位置 / 嚴重：煞星直接衝破格局核心條件）

    → 讀取 references/geju.md

    第四步：時間推算

    1. 生年四化 □ — 一生基調，讀取 references/sihua.md 天干四化表
    2. 大限 □ — 當前所處十年大限的星曜配置與走勢，讀取 references/daxian-liunian.md
    3. 流年 □ — 當前年份流年命宮、流年四化，同上文件
    4. 身宮 □ — 身宮所在宮位代表後天運勢重點和後半生命運傾向，讀取 references/daxian-liunian.md

    時間推算結果以表格呈現：

    維度 內容
    時間範圍 年份（重要事件細化到月）
    吉凶屬性 吉利 / 不利 / 中性
    影響程度 輕微 / 中等 / 重大
    事件性質 可能的事件類型
    應對策略 不利時期的行動建議

    第五步：聚焦問題分析

    A. 三合派核心判斷（70%） - 基於前四步的結果，聚焦與問題直接相關的宮位 - 問事業 → 官祿宮三方四正；問感情 → 夫妻宮三方四正；依次類推

    B. 輔助流派驗證（30%）— 可跳過 - 飛星四化使用 references/sihua.md，河洛卦象使用 references/heluo-guaxiang.md - 若 reference 數據不足以支撐飛星/河洛/欽天分析，跳過該流派，不要編造 - 可跳過時註明：「[流派名]驗證因參考資料有限，此處略過」

    C. 綜合結論 - 具體、有針對性，避免「運勢平平」等模糊表述 - 用具體的宮位星曜組合來支持結論

    D. 實用建議 - 標註時間節點和行動方向 - 若分析結果不利，給出調適方向和應對策略
